# Dataset

`ai4i2020.csv` is the AI4I 2020 Predictive Maintenance Dataset from the UCI Machine Learning Repository. It is synthetic, contains 10,000 instances and 14 columns, and is distributed under CC BY 4.0. Suggested dataset citation: *AI4I 2020 Predictive Maintenance Dataset* (2020), UCI Machine Learning Repository, [doi:10.24432/C5HS5C](https://doi.org/10.24432/C5HS5C). Retain attribution under the [CC BY 4.0 license](https://creativecommons.org/licenses/by/4.0/).

To obtain a fresh copy, use UCI's download link on that page, extract `ai4i2020.csv` from the archive, and place it here. The included CSV has 10,000 rows and 14 columns, matching the UCI dataset schema.
